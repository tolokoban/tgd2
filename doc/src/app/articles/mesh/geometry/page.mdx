# Geometry

## Shapes

- [Box](#/articles/mesh/geometry/shape/box): a box with each axis perpendicular to the world axes.
- [Gltf](#/articles/mesh/geometry/shape/gltf): a mesh primitive extracted from a glTF binary file.
- [Grid](#/articles/mesh/geometry/shape/grid): a rectangle subdivided in quads, useful for vertex deformations.
- [Path](#/articles/mesh/geometry/shape/path): a flat shape filled from an SVG path.
- [Plane](#/articles/mesh/geometry/shape/plane): a rectangle made of two triangles.
- [SphereIco](#/articles/mesh/geometry/shape/sphere-ico): a pseudo-sphere subdivided from a regular tetrahedron.

## Tools

- [join](#/articles/mesh/geometry/tool/join)
- [subdivision](#/articles/mesh/geometry/tool/subdivision): subdivide a geometry, like the Subdivision Surface modifier of Blender.
