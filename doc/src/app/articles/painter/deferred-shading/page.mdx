# [TgdPainterDeferredShading](docs/classes/TgdPainterDeferredShading.html)

Framebuffer that holds the surface normals, the depth, the albedo, the material parameters and the emission of meshes,
seen from the camera of the context. The five textures are rendered in a single pass.
It is the first pass of a deferred shading pipeline.

<Demo />

- `textureNormals` (`RGB10_A2`) holds the normals in the camera space, encoded as `N * 0.5 + 0.5`.
  The alpha channel is 1 where a mesh has been painted, and 0 elsewhere.
- `textureDepth` (`DEPTH_COMPONENT24`) is the depth buffer of the pass. It holds the window depth,
  between 0 (near plane) and 1 (far plane), which is **not linear** with a perspective camera.
  Unproject it with the inverse projection matrix to get the position in the camera space:
  `vec4 p = uniProjectionMatrixInverse * vec4(vec3(uv, depth) * 2.0 - 1.0, 1.0); vec3 pos = p.xyz / p.w;`
- `textureAlbedo` (`RGBA8`) holds the color computed by the material of each mesh.
  Use an unlit material if you want the pure albedo, without any lighting.
- `textureMetallicRoughnessSpecularBakedAO` (`RGBA8`) holds the metallic (R), roughness (G),
  specular (B) and baked ambient occlusion (A) of each mesh. They are read from the optional `textures`
  of a `TgdMeshWithTextures`, in the RED channel unless `metallicChannel`, `roughnessChannel`,
  `specularChannel` or `bakedAOChannel` says otherwise. A missing texture uses the default value:
  metallic 0.0, roughness 0.5, specular 0.5 and baked AO 1.0.
- `textureEmission` (`RGBA8`) holds the color of the light emitted by each mesh, read from the optional
  `emission` texture of a `TgdMeshWithTextures`. It is `(0, 0, 0, 1)` when the texture is missing.

As in `TgdPainterMeshes`, a mesh without `material` uses the one of its closest ancestor,
and it is not painted if there is none.

Use the buttons to see the scene, the normals, the depth (linearized), the albedo, the material parameters or the emission.
The box has a metallic texture (from left to right) and a specular one (from top to bottom),
while the helmet takes its metallic, roughness, baked AO and emission from the textures of its GLB file.
glTF stores metallic in the BLUE channel and roughness in the GREEN channel of the same image,
so the demo uses this texture twice, with `metallicChannel: "b"` and `roughnessChannel: "g"`.
The GLB file has no specular texture, so the helmet uses the default specular value.

Use [TgdFilterDeferredShading](#/articles/painter/deferred-shading/lighting) to compute the lighting from these textures.

Set the `enableIDs` option to write the `id` of the meshes in `textureIDs`, for [object picking](#/articles/painter/deferred-shading/picking).
